# A 90-second demo

1. Start the static explorer. Open the 2023 held-out cohort.
2. Point out that the model was frozen after calibration outcomes matured, before 2023.
3. Open a top-ranked paper and show title/metadata contributions. Explain that these are associations, not scientific merit.
4. Click **Reveal future outcomes**. Compare predicted attention with actual 2024 citation counts.
5. Switch to 2024 and repeat with 2025 outcomes. Never preselect only success cases.
6. Save two papers and export the filtered results. Reading lists persist locally.
7. Score a new title with manual metadata. The exact same model runs in the browser.
8. Open **Model evidence**. Show the simpler baseline beating the text-enhanced model. Explain why retaining a negative finding makes the experiment inspectable.
9. State the important qualification: current metadata snapshot and next-calendar-year outcome, not an exact twelve-month, archival evaluation.

Live search additionally requires the included Python server. No invented impact scores, fake citations or synthetic benchmark results are used.
